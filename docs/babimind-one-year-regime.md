# BabiMind — مدل افق یک‌ساله بازار

این سند مشخصات لایهٔ جدید **One-Year Market Regime** را ثبت می‌کند. هدف، تبدیل تحلیل یک‌سال گذشته و سناریوی یک‌سال آینده به یک ورودی پایدار برای BabiMind است.

## یافتهٔ مرجع ۱۲ماهه

در حوالی شهریور ۱۴۰۵، شاخص کل نسبت به شهریور ۱۴۰۴ رشد بسیار بزرگ‌تری از دلار آزاد داشته است. بنابراین BabiMind نباید رشد بورس را صرفاً «جبران افت ریال» فرض کند؛ باید احتمال **re-rating** را نیز بررسی کند.

مقادیر مرجع فعلی تقریبی‌اند و هر ران باید آنها را با دادهٔ همان `as_of` بازسازی کند:

| متغیر | شهریور ۱۴۰۴ | شهریور ۱۴۰۵ | تغییر تقریبی |
|---|---:|---:|---:|
| شاخص کل | ۲.۶۲–۲.۶۳M | ۷.۱۲M | +۱۷۱٪ |
| دلار آزاد | ~۹۷.۵K | ~۲۳۶K | +۱۴۲٪ |
| شاخص/دلار | ~۲۷ | ~۳۰.۲ | +۱۲٪ |

این اعداد **دادهٔ seed برای منطق مدل هستند، نه دادهٔ realtime**. در هر اجرای جدید، مقدار واقعی باید از منابع اولویت‌دار جایگزین شود.

## منطق مدل

BabiMind برای افق یک‌ساله باید همزمان این موارد را بسنجد:

1. بازده ۱۲ماههٔ شاخص
2. بازده ۱۲ماههٔ دلار آزاد
3. نسبت شاخص به دلار و تغییر آن
4. نقدینگی و ارزش معاملات
5. تورم
6. سود شرکت‌ها و re-rating
7. مس و سایر کامودیتی‌های جهانی
8. ورود/خروج پول حقیقی و رفتار حقوقی
9. P/E و ارزش دلاری بازار
10. تأیید زنجیرهٔ آپشن‌ها

هیچ‌کدام به‌تنهایی سیگنال خرید نیستند.

## رژیم‌ها

- **Bullish:** شکست/تثبیت بالای ۷.۲۵M همراه با تأیید جریان پول، نقدینگی و سودآوری.
- **Neutral:** نوسان حدود ۶.۵M تا ۷.۲۵M با سیگنال‌های ترکیبی.
- **Risk-off:** شکست ۶.۵M، مخصوصاً همراه با شوک دلار، خروج حقیقی و افت breadth/AD.

## سناریوهای ۱۲ماهه

| سناریو | محدوده |
|---|---:|
| Correction / Stress | ۵.۸–۶.۳M |
| Base | ۸.۲–۹.۰M |
| Bullish | ۹.۵–۱۰.۸M |
| Super Bullish | ۱۱.۵–۱۳M |

سطح ۶.۵M **invalidation اصلی ساختار صعودی این مدل** است و ۷.۲۵M **سطح تأیید شکست** محسوب می‌شود.

## اتصال به BabiMind

این لایه باید بعد از Data Validation و قبل از Scenario & Forecast تغذیه شود و خروجی آن به Decision Engine، Economic Graph، Flow/Rotation، Options، Game Theory، System Dynamics و Model Memory ارسال شود.

خروجی استاندارد:

```text
regime
scenario_probabilities
target_ranges
risk
confidence
invalidation
factor_contribution
change_vs_previous_run
```

## قواعد کنترلی

- نسبت سال ۱۳۹۹ فقط **historical anchor** است و fair value نیست.
- احتمال سناریوها باید جمعاً ۱ شود.
- هیچ look-ahead مجاز نیست.
- دادهٔ ناقص صفر محسوب نمی‌شود (`MISSING_IS_NOT_ZERO`).
- بازده تاریخی به‌تنهایی نمی‌تواند سیگنال خرید ایجاد کند.
- هر خروجی باید `as_of`، منبع و confidence داشته باشد.
