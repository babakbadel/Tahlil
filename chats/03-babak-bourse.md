# چت ۳ — بورس بابک

## هدف
توسعه مدل حرفه‌ای تحلیل بورس ایران با تمرکز بر داده‌های واقعی و زمان انتشار اطلاعات.

## مهارت‌ها و منابع مورد نیاز
- Codal برای افشای اطلاعات شرکت‌های ایرانی
- صورت‌های مالی
- گزارش حسابرس
- گزارش فعالیت ماهانه
- اطلاعات بااهمیت
- تصمیمات مجامع
- افزایش سرمایه
- EPS و برآوردها
- فایل‌های PDF و Excel
- Market Data
- Game Theory
- Price Action
- Technical Analysis و تمام اندیکاتورهای مرتبط

## الزامات داده
- تاریخ‌های جلالی باید درست تفسیر و نرمال‌سازی شوند.
- timestamp انتشار اطلاعات باید از تاریخ وقوع رویداد تفکیک شود.
- برای جلوگیری از look-ahead bias، مدل نباید اطلاعاتی را قبل از زمان واقعی انتشار وارد تحلیل گذشته کند.

## Codal Skill
مهارت Codal از مخزن amirziveh/codal-skill با مسیر SKILL.md به workflow تحلیل بورس ایران اضافه شد/به‌عنوان مهارت مورد نیاز مشخص شد.

## معماری مورد نظر
Market Data + Codal + تحلیل بنیادی + Technical Analysis + Price Action + Game Theory + Event/Decision Layer.

## ارتباط با بابی هوش
این لایه‌ها باید در مدل «بابی هوش» به‌صورت یک سیستم یکپارچه تحلیل بازار ایران استفاده شوند.

## نکته مهم
این فایل بازسازی ساختاری محتوای قابل دسترس از چت است؛ متن خام و کامل تاریخچه پیام‌های چت در محیط فعلی در اختیار ابزار GitHub نیست.
